# SHAKIL STORE

A clean, responsive Bangla + English storefront concept for a mixed-product ecommerce shop.

## Preview
This project is configured for Vercel deployment from the `main` branch when the GitHub integration is active.

## Current features
- Responsive storefront and product grid
- Search and category filters
- Cart quantity controls and subtotal
- Demo admin panel for local product and stock edits
- Bangla + English interface details

## Important: demo status
This repository currently contains a **front-end prototype**, not a production-ready ecommerce system.
- Cart and admin edits are browser-local only.
- Checkout is intentionally a preview; it does not create orders or collect customer data.
- No real bKash/Nagad gateway, COD order processing, authentication, database, inventory sync, courier tracking, or admin security is connected.
- Do not enter real customer, personal, or payment information.

Before accepting real orders, add a secure backend/database, authenticated admin roles, server-side validation, order management, and approved payment-provider integrations. Keep all API keys in Vercel environment variables, never in browser code.
